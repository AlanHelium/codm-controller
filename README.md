# CODM 手柄转换器 v3.5.15

Windows 桌面手柄工具。全部功能免费，赞赏自愿。

[下载最新版](https://github.com/AlanHelium/codm-controller/releases/latest) · [使用说明](必看%20README.TXT) · [源码构建](BUILD.md) · [问题反馈](https://github.com/AlanHelium/codm-controller/issues)

## 功能

- 实体手柄转换为虚拟 DS4，支持手感曲线、死区、横纵灵敏度及 ADS 倍率。
- 单键、双键组合映射，长按快捷交互及按键占用提醒。
- 光标辅助、移动与奔跑、震动、TTS 和外部载入音频提示。
- 一屏总览、配置管理、中英文界面、设备诊断与按键测试。
- 安装、清理卸载、独立连接修复工具，保留用户设置。

## 安装与使用

1. 下载 Setup.exe，正常关闭旧转换器和游戏后安装；已有可用组件会复用。
2. 接入手柄，确认输入与连接组件就绪，再启动转换和游戏。
3. 在手感调校、键位映射中按需调整。已有配置沿用，不必先卸载旧版。

免安装版请完整解压，先运行「准备组件.cmd」，再打开主程序。它仍依赖系统级共享驱动，并非零安装依赖。

## 连接修复

打开「工具与配置 → 修复连接组件」，也可运行程序目录的「修复连接.cmd」。主程序打不开或旧版没有入口时，使用独立 Repair.zip。
工具先检查，正常时不重装；不会自动重启。Windows 确实仍在释放驱动时可能需要手动重启，不能承诺所有驱动维护都零重启。
