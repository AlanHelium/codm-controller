CODM 手柄转换器 v3.4.3
作者：Burrito　　使用前请先读完本文件
============================================================

【先看这五条】
1. 本包适用于 Windows 10/11 x64。主程序自带 .NET 运行时，无需另装 .NET。
2. 先退出游戏和旧转换器，再安装。使用时先启动转换、等成功后再打开游戏。
3. 安装包括主程序、卸载程序、ViGEmBus 与 HidHide 两项官方手柄驱动。
4. 本安装包和主程序尚未代码签名。出现安全软件提示时，先核验来源、SHA256
   与扫描结果；不能只凭这份说明认定提示一定是误报。不要关闭系统防护。
5. 卸载若显示“待重启”，表示清理尚未完全生效；请选择现在重启或稍后重启，
   并完成重启后的复查。软件不会未经选择自动重启电脑。

一、安装了什么、放在哪里
------------------------------------------------------------
安装位置可自行选择或输入。请使用独立子文件夹，不要直接选择磁盘根目录、
桌面、文档文件夹或已有其他文件的目录。默认位置是当前用户：
%LOCALAPPDATA%\Programs\Burrito\CODMControllerProbe

所选安装目录中包含：
- CODMControllerProbe.exe：已验证的 v3.4.3 主程序。
- CODMControllerProbeUninstaller.exe：卸载与重启后复查程序。
- 必看 README.TXT：本教学、注意事项和说明。
- 赞赏码.png：作者提供的赞赏码原图，独立文件。
- components：两项官方驱动安装包，用于安装、修复及卸载入口恢复。
- installation.json：本版本的安装与清理记录；以及操作日志。

系统中安装或复用以下组件：
- ViGEmBus 1.22.0 安装包：创建虚拟手柄设备，供游戏接收转换后的输入。
- HidHide 1.5.230 安装包：运行转换时隔离实体手柄，避免原动作绕过改键。
  文件为 Nefarius 官方签名包。两者是系统共享驱动，也可能被其他手柄软件使用。
  已就绪的组件会复用；失效的组件会通过官方安装流程准备或修复。
  官方包还可能包含其配置客户端、维护服务和卸载登记，按官方包自身定义安装；
  完整卸载所选驱动时也通过官方卸载流程移除这些组件，不冒充只装了两个文件。

安装还会创建开始菜单快捷方式，并在“设置→应用→已安装的应用”注册卸载入口。
不会修改游戏文件。安装不清除已有手感、键位或授权配置，也不会自动打开赞赏码。
程序运行时的配置、授权、语音和维护记录在当前用户的：
%APPDATA%\CODMControllerProbe 与 %LOCALAPPDATA%\CODMControllerProbe。
自包含运行时可能在临时目录生成本程序缓存；卸载结束时安排清理这些产品缓存。

二、第一次使用：建议先用 USB
------------------------------------------------------------
1. 退出游戏、模拟器和其他手柄转换器。连接支持数据传输的 USB 数据线。
2. 启动 CODM 手柄转换器。确认首页型号、图片与连接状态对应实体手柄。
   虚拟输出设备不会作为实体手柄冒充连接。
3. 等待首页显示“转换已成功启动”，然后打开游戏进入训练场。
4. 先测试方向、摇杆回中、跳跃、换弹、开镜和射击，再调整手感与键位。
5. 停止转换或正常退出会释放键盘状态、断开虚拟输出，并恢复本次实体隐藏状态。
   “工具与配置→退出后打开清理工具”通常保持关闭；需要清理时优先用配套卸载器。

如果提示实体隔离未生效：关闭游戏，重新插拔手柄后重试；仍不正常时查看
“工具与配置→驱动与连接诊断”。驱动装好但设备仍使用旧设备栈时可能需要重插。
某些首次安装或卸载需要重启，以安装/卸载界面的实际提示为准。
请勿同时运行旧版和新版；已经启动的旧游戏可能保留实体手柄句柄，绕过改键。

三、手感、动作交换和键盘映射
------------------------------------------------------------
- 手感调校：选择响应曲线，调整 1～20 档灵敏度与开镜倍率（%）。
  先一次只改一项，在训练场比较效果。“恢复默认”针对当前手感调校，保留键位。
- 动作交换：进入“键位映射→设置游戏动作与组合键”。例如将跳跃改到原换弹键，
  换弹会交换到原跳跃键；按新来源只应触发新动作，不应同时执行两个动作。
- 手柄→键盘：进入“编辑键盘映射”，对对应物理手柄键点“重设”，按下目标键。
  映射后的物理来源会替代原手柄事件；请先确认该键盘键在游戏中确实有功能。
- 改绑定、清除绑定或停止转换时旧按住状态会释放。多个来源使用同一个键时，
  松开其中一个不会取消仍被其他来源按住的同一键。
所有设置和录键在主窗口内编辑。配置会自动保存，无需退出设置页面。

四、WASD 与外圈奔跑
------------------------------------------------------------
进入“移动与奔跑”开启 WASD。左杆轻推为走路，推到外圈按住 Shift 奔跑，回中释放。
建议先把外圈阈值设为 90%，再按实际最大推幅调整；查看页面中的实时推幅提示。
游戏的键盘奔跑方式需设置为“按住 Shift”；先用实体键盘 W+左 Shift 验证设置。
WASD 方向长按会发送重复消息，Shift 本身不自动重复。
外圈 Shift 的系统按住状态只在游戏前台生效，切出游戏或停止转换时释放。
原生摇杆、WASD、实验触屏是不同移动方案，请按页面说明选择，不要混用。
想回到原生摇杆移动时关闭 WASD，再测试 L3 奔跑设置。

v3.4.1 输入修复已由用户使用 DS5 USB 实测：原生手感、跳跃/换弹交换和 WASD 外圈奔跑可用。
v3.4.2 保留相同输入核心，并完成免费功能、设备隔离和恢复检查。
v3.4.3 修复曲线编辑页滑块不生效的问题；41 项回归检查验证实时曲线、参数保存、
切换摇杆和重开页面。输入核心未修改；本次未重新进行真实游戏或设备隔离测试。
DS4、DSE 以及不同 Xbox 硬件仍需逐台验证；识别到型号不等于所有功能已实测通过。

五、卸载与“是否清理干净”
------------------------------------------------------------
可从“设置→应用→已安装的应用→CODM 手柄转换器→卸载”启动，也可打开安装目录
中的 CODMControllerProbeUninstaller.exe。请先正常退出游戏和转换器。

卸载界面会让你看到并选择：
- 移除 ViGEmBus / HidHide 共享驱动（默认选中）。这可能影响同样依赖它们的软件；
  如需保留可取消，结果会明确列出保留项，不会显示“完全清理”。
- 删除当前用户的手感、键位、授权、语音及维护记录（默认选中）。删除后无法恢复；
  需要保留时先导出配置或取消这一项。

卸载先恢复实体输入，再通过官方卸载器移除所选驱动，检查服务、过滤器注册、
驱动文件、官方安装项与精确识别的驱动包，清理本安装清单里的文件、快捷方式
和卸载入口。不会盲目整目录删除用户另放的文件，也不直接强删运行中的驱动文件。
若官方卸载后留下旧版孤立组件，会先核对过滤器、设备与服务引用、精确服务路径
及已知官方驱动文件 SHA256，再请求 Windows 正常停止服务；确认停止后才即时清理
对应登记与文件。不能正常停止或文件由系统管理时，通过 Windows 登记重启清理，
保留复查入口；重启前不宣称已经清完。文件不匹配或引用核对失败时保留并说明原因。
停止的旧版 HidHide.sys 若受系统权限保护，会使用仅处理该固定文件的临时
Windows Installer 维护项清理，随后移除维护项；失败会保留详细记录供继续清理。

结果有三类：
1. 已核验移除：所选项目通过检查；关闭卸载窗口后清理临时副本与本程序运行缓存。
2. 按选择保留：例如共享驱动或个人配置保留，会列清具体项目。
3. 尚未完成/待重启：如被占用、官方卸载失败或需要重启，会显示原因和剩余项目；
   保留卸载器及恢复文件供继续操作。需要重启时提供“立即重启”和“稍后重启”。
   重启后会尝试继续复查；若没有自动弹出，请从开始菜单继续卸载或运行剩余卸载器。
   没有复查完成前，不应把“已安排删除”理解为“已完全清除”。

卸载范围是本安装版本及选定的两项驱动，不会自动删除你在桌面或下载目录保存的
其他旧版、压缩包、备份或第三方软件。Windows 自身安装历史、事件日志和系统维护
缓存由 Windows 管理，本程序不会擦除系统历史以隐藏安装行为。
需要留存详细记录时，在卸载结果页自行保存；否则临时操作记录随临时副本清理。
