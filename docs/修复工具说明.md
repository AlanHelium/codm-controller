# v3.5.18 简明使用说明

## 安装
关闭游戏与旧转换器，打开Setup，点击“立即安装”。安装位置可在“安装选项”中更改；覆盖升级保留设置，不必先卸载旧版。
文件、共享驱动和隔离规则自动准备。安装不要求先插手柄做实机验证，启动转换时再自动验证实际输入。

## 修复
安装目录内直接双击“修复工具.exe”，关闭游戏、接入手柄后点“开始修复”。无需再下载独立包；recovery和components目录是修复必需文件，请保留。
工具检查程序文件、驱动、白名单、反向模式、实体隐藏和虚拟设备排除。修复前备份相关规则或损坏文件，保留手感、键位和音频。完整独立修复包仍可用于整个安装目录严重损坏的情况。

## 卸载
通过系统已安装应用，或安装目录“卸载程序.exe”，点击“卸载并清理”。默认清理程序、当前用户配置和两项共享驱动。其他手柄软件可能依赖共享驱动；需要保留时展开“卸载选项”取消相应项。
清理后核对残留。无法删除、非本软件文件或Windows仍持有驱动时，不宣称完全清理。真实待释放状态可能需要手动重启，工具不会自动重启；重启后续办会继续复查。
本机其他用户的个人目录不在卸载范围，用户自行放入目录的未知文件不会被盲删。

## 详细信息
安装、卸载和修复默认只显示当前阶段和结果。点“展开详细记录”查看完整步骤、错误原因和保留项，可保存记录。
本次完成编译与交付包核对，未重新执行本机驱动安装卸载、GUI或客户故障验证。不能保证所有未知系统错误都自动修复。
