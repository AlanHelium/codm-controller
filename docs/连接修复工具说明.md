# 连接修复工具 v3.5.15

用于“驱动已安装但暂时无法调用”、驱动缺失或安装不完整等连接组件问题。

## 打开方法

- 新版软件：设置 → 工具与配置 → 修复连接组件。该入口会先正常退出转换器，保存设置并恢复输入会话。
- 安装目录或免安装目录：双击“修复连接.cmd”。
- 独立修复包：将ZIP完整解压到独立文件夹，双击CODMControllerRepair.exe，允许管理员授权。请保留components文件夹。

独立包适用于主程序打不开或旧版没有修复入口的情况；无需先卸载主程序。

## 使用

打开后自动检查。组件正常会显示“无需修复”，不会重新安装正常组件。
需要修复时，先正常退出转换器、游戏及模拟器，再点“开始修复”。使用包内已校验的官方组件，不删除手感、键位、授权和音频配置。
完成后重新打开转换器。原有驱动可用时复用；缺失/不完整时修复对应组件。

如果上次卸载还没完成，或Windows仍在释放驱动，会单独说明。这类状态不能保证一次修复且零重启；工具不会自动重启，也不清除Windows的待删除记录来假装成功。

异常时可点“保存记录”发给作者。最近一次结果也保存在：
`%LocalAppData%\CODMControllerProbe\maintenance\connection-repair-last.json`

本工具检查的是连接组件。组件正常并不等于已经验证游戏内键位或实体输入隔离；这些问题请使用软件内的设备诊断和按键测试。
