# 修复工具 v3.5.18 · 白名单与隔离修复

正常关闭转换器、游戏和模拟器，接入要修复的实体手柄。完整解压Repair.zip，双击CODMControllerRepair.exe，点“开始修复”。components和recovery文件夹都要保留。

新增：核对当前转换器EXE对应的NT设备路径白名单；关闭反向白名单；移除已知游戏、浏览器及共享dotnet宿主的错误豁免；排除在场虚拟设备及父节点的误隐藏；恢复上次中断的本工具隔离会话。
修改前备份规则。短暂创建中性虚拟DS4并隐藏关联实体集合，使用未豁免的独立进程确认实体访问被拒绝、虚拟DS4实际报告可读，再从转换器本身的新进程确认仍能打开实体与虚拟接口。验证后恢复待机规则，不留下测试虚拟手柄。
同一物理手柄的安全集合依据Container和父链关联；不按相同VID/PID盲目扩大，不隐藏键盘鼠标，不随意清空第三方规则。

未连接手柄时，只能确认静态规则和组件，结果会注明实机验证待接入。安装新版同样会检查修复隔离规则；若尚未连接手柄，不会将其算作驱动安装失败。
如果Windows仍持有旧输入句柄、驱动待释放、游戏/其他配置程序占用或硬件固件不兼容，可能无法当场完成；工具会保留具体失败步骤，不谎报成功。

保留手感/键位/音频，不自动重启，不结束游戏。规则备份与访问验证报告在 %LocalAppData%/CODMControllerProbe/maintenance/isolation-*；每次修复结果和官方安装日志同样在maintenance。
没有验证所有客户故障环境，不保证任何未知错误均可自动修复。
